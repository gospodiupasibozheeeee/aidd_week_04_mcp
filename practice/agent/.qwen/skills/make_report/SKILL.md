# Excel-отчёт по задачам

Получи актуальные задачи из локального TODO API через готовый скрипт; не переписывай задачи вручную. По умолчанию используется `http://127.0.0.1:5001`. Скрипт создаёт листы «Задачи» и «Сводка», рассчитывает показатели и не перезаписывает существующий файл.

Выполни из `practice/agent`, подставив требуемый путь и дату:

```bash
/Users/lendwye/anaconda3/bin/python .qwen/skills/make_report/generate_report.py --date 2026-11-10 --output ПУТЬ.xlsx
```

Если пользователь не указал дату, не передавай `--date`: будет использована дата сервера. Путь должен быть внутри рабочей папки. Если файл уже существует, не удаляй и не перезаписывай его: выбери новое имя или спроси пользователя. Убедись, что команда завершилась успешно, и сообщи путь и значения, напечатанные скриптом. Данные задач не изменяй.

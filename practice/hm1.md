# Домашнее задание 1

## Подготовка

Для отчёта выбрал Excel с двумя листами: на первом список задач с приоритетом, сроком и статусом, на втором сводка - сколько всего задач, сколько выполнено и просрочено, процент выполненных и количество по каждому приоритету.

## Без skill

Два раза попросил Qwen сделать отчёт и подробно описал формат. Каждый раз начинал новую сессию. Агент получал задачи через MCP и сам писал скрипт для Excel. В первый раз в отчёте были все 464 задачи. Сверил строки с API, ошибок не нашёл. Во второй раз агент включил только 100 задач, остальные 364 пропустил. Из-за этого сводка получилась неверной, хотя сами 100 строк совпали с API. Файлы отличались и оформлением: агент по-разному подписал показатели и записал сроки. Но главное - во втором случае он сказал, что отчёт готов, хотя тот был неполным.

## Со skill

Создал make_report. Там лежат SKILL.md с инструкцией, скрипт генерации отчёта и тесты. Скрипт получает задачи из локального API, считает показатели и создаёт Excel. Затем дважды попросил Qwen сделать Excel-отчёт, но формат и название skill не указывал. Оба раза он сам выбрал make_report, это видно в траекториях.
Оба отчёта со skill совпали по структуре и цифрам. Сверил их с API - расхождений не было. В этих запусках получилось быстрее и с меньшим расходом токенов, но попыток всего по две, так что точную экономию по ним оценивать рано.

## Описание skill

Попробовал три варианта description. С каждым два раза просил сделать отчёт, не называя skill:

1. Понятное описание про Excel-отчёт по задачам - make_report выбран оба раза.
2. Расплывчатое описание про помощь с данными и файлами - make_report не выбран ни разу. В одном запуске агент выбрал другой skill, xlsx.
3. Описание не по теме - make_report тоже не выбран ни разу.

Когда нужный skill не выбирался, агент сам искал данные и писал скрипт. Результаты и действия различались. В двух запусках с расплывчатым описанием он ещё установил openpyxl и et-xmlfile через pip. После эксперимента вернул понятное описание.

## Вывод

Со skill оба отчёта получились полными и верными, без него один из двух оказался неполным. Описание тоже важно: если не сказать, для чего skill нужен, агент может его просто не выбрать.
